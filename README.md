> MiniLibX를 활용하여 밑바닥부터 구현한 2D 타일 기반 미로 탈출 게임

---

## 🖥️ 장르 : 2D 탑뷰 어드벤처 (싱글 플레이)
맵에 배치된 모든 수집품을 모으고 탈출구로 탈출하는 2D 미로 탈출 게임입니다.

## ⏱️ 개발 기간
- 24.03.11 - 24.03.25

## 🧑 제작 인원
- 장현교 : 1인 개발 입니다.

## ⚙️ 개발 환경
- **Language** : C (C99 / GNU89)
- **Library** : MiniLibX (X11 기반 기본 그래픽 라이브러리)
- **OS** : Linux (Ubuntu / WSL2)
- **IDE** : Visual Studio Code / Vim

---

## 📌 주요 기능

### 맵 파싱 및 유효성 검증
- `.ber` 확장자 파일에서 맵 데이터를 읽어 2차원 동적 배열로 파싱했습니다.
- 맵이 직사각형 형태인지, 외곽이 모두 벽(`1`)으로 둘러싸여 있는지 유효성을 검사했습니다.
- 시작 지점(`P`), 탈출구(`E`), 수집품(`C`)의 필수 개수를 검증하고, 비정상적인 문자가 포함될 경우 에러 메시지와 함께 안전하게 종료되도록 설계했습니다.
- DFS(Flood Fill) 알고리즘을 활용해 플레이어가 모든 수집품을 획득하고 탈출구에 도달 가능한 유효 경로가 존재하는지 사전에 판별했습니다.

### 렌더링 파이프라인
- XPM 이미지 포맷의 스프라이트(벽, 바닥, 수집품, 플레이어, 탈출구)를 메모리에 로드하여 타일 단위로 렌더링했습니다.
- 맵 배열의 좌표와 윈도우 픽셀 해상도를 1:1로 매핑하여 윈도우 창에 출력했습니다.

### 캐릭터 조작 및 게임 로직
- 키보드 이벤트 훅(`mlx_key_hook`)을 연결해 WASD 및 방향키 입력을 처리했습니다.
- 이동하려는 타일의 상태를 사전에 판별하여 벽 통과를 차단하고, 수집품 습득 시 카운트를 갱신했습니다.
- 모든 수집품을 획득한 상태에서만 탈출구가 활성화되어 게임을 클리어할 수 있도록 구현했습니다.
- 플레이어의 유효 이동 횟수를 터미널 표준 출력(stdout) 및 화면에 실시간으로 기록했습니다.

### 이벤트 처리 및 리소스 관리
- 윈도우 창 닫기 버튼(Red Cross) 및 `ESC` 키 입력 이벤트를 감지하여 안전하게 프로그램을 종료하도록 처리했습니다.
- 프로그램 종료 시 로드된 이미지 인스턴스, 윈도우 인스턴스, 2차원 맵 동적 할당 메모리를 누수 없이 순차적으로 해제했습니다.
